# Optional dependencies for the multi-ring (MR) segmentation subsystem.
#
# NOT required by the base framework or by the watchmal / graph cores. Install these
# only to run multi-ring configs (core: caverns, engine: multiring/segmentation) — a
# plain `python main.py --config-name=resnet_train` does not need them, because the MR
# modules are imported solely through their Hydra `_target_`.
#
#   pip install -r requirements-multiring.txt
#
# spconv: sparse 3D convolutions + PointToVoxel (the encoder and voxelizer require it).
#         Install the CUDA build matching your toolkit, e.g. `pip install spconv-cu120`
#         (or spconv-cu118 / spconv-cu126 ...). There is no generic `spconv` wheel for GPU.
# scipy:  Hungarian matching (scipy.optimize.linear_sum_assignment) in the set losses.
#
# spconv-cu120
scipy
