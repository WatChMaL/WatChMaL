# Optional dependencies for the multi-ring (MR) segmentation subsystem.
#
# scipy (Hungarian matching in the set losses) is the `multiring` extra:
#
#   pip install -e .[multiring]
#
# spconv is installed BY HAND, because it is not a single PyPI package: you must
# pick the build matching your toolkit, e.g. `pip install spconv-cu120`
# (or spconv-cu118 / spconv-cu126 ...). There is no generic `spconv` wheel for GPU,
# so it cannot be an extra. It is NOT required by the base framework or by the
# watchmal / graph cores - a plain `python main.py --config-name=resnet_train`
# does not need it, because the MR modules that use it are imported solely through
# their Hydra `_target_` (the sparse-3D-conv encoder and the PointToVoxel voxelizer).

# Optional extra: the `diagnostic_multiring` submodule adds training diagnostic plots.
# It is lazy-imported and OFF by default (tasks.train.diagnostic.enabled: []), so it is
# not needed for normal runs. To enable it, add it as a git submodule and turn it on in
# the config.
